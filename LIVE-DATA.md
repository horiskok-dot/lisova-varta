# Відкриті дані та їхні межі

## Погода й спека

[Open-Meteo](https://open-meteo.com/en/docs) надає температуру, вологість, вітер і прогноз для центру мапи. Це дані моделі з указаним часом, а не вимірювання на місці. Ключ для некомерційного відкритого API не потрібен. Браузер звертається до Open-Meteo напряму; серверний обробник є резервним шляхом. Користувач бачить помилки та час даних.

## Населені пункти й контури

Пошук працює за вбудованим каталогом [GeoNames Ukraine](https://www.geonames.org/export/) із 33 743 населених пунктів. Каталог не гарантує наявності кожного місцевого топоніма. Окремий шар Дніпра містить 536 контурів лісів, парків і водойм, зібраних із OpenStreetMap 19 жовтня 2026 року. Він охоплює вибрані ділянки в межах міста, а не всі об’єкти. Контур не стає записом журналу, доки користувач не вибере місце й не збереже його.

## Водні об’єкти OpenStreetMap

Шар «Місця перевірки води» використовує вбудований знімок 14 198 точок OSM в адміністративній області України від 22 жовтня 2026 року. До нього входять лише вузли з `emergency=fire_hydrant`, `water_tank` або `suction_point`; координати не генеруються з центрів будівель чи водойм. Відомі приватні/закриті та внутрішні об’єкти виключено за тегами. Відсутність відповідних тегів не доводить публічний доступ або справність. Покриття нерівномірне: наприклад, у вибраних межах Дніпра таких точок у знімку немає. Для Дніпра є окрема кнопка 121 контуру водойм, де конкретне місце огляду вибирає людина. Оновлення знімка: `node scripts/build-water-sites.mjs` (один запит Overpass, виконується вручну).

Для локальної ділянки навколо центру мапи [read-only API OSM](https://wiki.openstreetmap.org/wiki/API_v0.6) повертає водойми, гідранти, резервуари й місця забору води. При щільній забудові запит автоматично звужується, якщо API відхиляє завелику відповідь. Положення полігона на мапі не означає безпечну точку доступу: користувач сам вибирає місце для журналу й перевіряє його на місцевості. Покриття залежить від наповнення OSM.

## Теплові аномалії NASA FIRMS

Використовується [публічне європейське CSV-вивантаження VIIRS S-NPP](https://firms.modaps.eosdis.nasa.gov/active_fire/) за останні 24 години. Сервер фільтрує його за видимою областю мапи та показує час спостереження й завантаження. Теплова аномалія не дорівнює підтвердженій лісовій пожежі; нуль позначок не доводить відсутності пожеж. Інші супутники поки не підключені. Для цього публічного вивантаження ключ не потрібен.

## Сервер, офлайн і приватність

Сервер дозволяє лише визначені джерела, перевіряє координати й розмір області та не працює як довільний URL-проксі. Кеш у пам’яті: погода й NASA — 15 хвилин, OSM — 24 години. Публічні API не гарантують безперервної доступності. Вміст журналу й фото зберігаються локально на пристрої та не надсилаються цим застосунком до хмари.

Польовий режим скасовує поточні запити й вимикає онлайн-підкладку. Автономна оболонка не кешує сторінки входу замість застосунку або відповіді API замість даних. Під час прямого звернення до Open-Meteo провайдер отримує вибрані координати чи назву населеного пункту та звичайну мережеву IP-адресу; ключі або журнал не передаються.

Старі незмінені навчальні записи першої версії прибираються з активного журналу; повна копія старого стану зберігається в локальному сховищі для відновлення. Змінені користувачем записи залишаються. Командної синхронізації та дорожньої маршрутизації немає.
