# Перевірка версії 0.8.0 · 22 жовтня 2026

## Автоматично

`npm test` — **47 із 47 перевірок пройдено** локально на Node.js 24.19.0. Вони охоплюють валідацію API, час і формат даних NASA, геометрію OSM, каталог Дніпра, алгоритм плану огляду, GPX, українські числівники, автономний кеш і робочі сценарії журналу.

Додатково для 0.8 перевірено походження й унікальність 14 198 точок OSM, відсутність вигаданих берегових відрізків при неповній геометрії, кілька місць огляду однієї водойми, скасування конфліктного вибору початкової точки, чекліст без дублювання, групування щільних об’єктів, збереження відкритого попереднього перегляду при переміщенні мапи та пошук, розпочатий до завантаження каталогу.

Сценарії інтерфейсу перевіряють створення запису лише після явного збереження, вибір місця доступу до води, чернетку, фото, завдання, експорт/імпорт, нестачу пам’яті, конфлікт двох вкладок і польовий режим. DOM-тести використовують контрольовані заміни мапи й мережі; вони не перевіряють геометрію рендерингу браузера. Окремий тест перевіряє, що сторінка входу не потрапляє в автономний кеш як застосунок.

Публічний репозиторій також запускає `npm ci`, `npm test` і `npm run build` через [GitHub Actions](https://github.com/horiskok-dot/lisova-varta/actions/workflows/check.yml).

## Перегляд інтерфейсу й збірок

Інтерфейс переглянуто на ширинах 320, 390, 768 і 900 пікселів та в звичайному вікні ПК. Шар Дніпра перевірено окремо на ПК і телефонній ширині 390 пікселів: відкриття контуру, посилання на OSM, вибір точки й незбереження скасованої чернетки.

Windows-пакет пройшов запуск із `--smoke-test`: мапа, основна логіка, інтерфейс і SVG-логотип завантажилися, сторінка відкрилася без випадкового прокручування. Android APK успішно скомпільовано через `assembleDebug`. Фізичний Android-пристрій і системні дозволи в цьому проході не перевірялися.

У локальному браузері перевірено пошук Дніпра, 536 контурів, погоду Open-Meteo, воду OSM і API NASA FIRMS. Зовнішні сервіси можуть повертати помилки або порожні результати; нуль супутникових позначок не означає відсутності пожеж. Польового пілоту та незалежної оцінки точності алгоритму ще немає.

У проході 0.8 додатково переглянуто 121 водний контур Дніпра, групи гідрантів у Львові, відкриття джерела OSM, чернетку гідранта з чеклістом і її скасування без зміни журналу. Нові дані не означають, що кожне місце було фізично або вручну перевірене.
