# Лесной дозор · 0.3

Полевой журнал подготовки к лесным пожарам с реальными открытыми данными. Учебные точки при первом запуске не создаются. Описание подключений и их ограничений: [LIVE-DATA.md](LIVE-DATA.md).

## Запуск

Установите Node.js 24.15 или новее, затем в этой папке выполните `npm start` и откройте http://localhost:4173. Для запуска установка пакетов и API-ключи не нужны. Для автоматических тестов сначала выполните `npm ci`. Не запускайте через file://: автономная загрузка требует HTTP localhost или HTTPS. Исходники интерфейса в `web/`, API в `worker/`. `npm run build` создаёт Worker со встроенными ресурсами в `dist/server/index.js`.

## Возможности

- Реальная онлайн-карта OpenStreetMap через локально поставляемый Leaflet 1.9.4.
- Добавление точек кликом по карте или по координатам; тип, приоритет, состояние, дата проверки, ответственный и срок устранения.
- Фото с локальным уменьшением до 900 пикселей, просмотр и удаление.
- Поиск, фильтры, задачи и история изменений.
- План проверок с ограничением времени, временем осмотра и возвратом на базу; выбор лучшего из трёх вариантов по суммарной условной важности; экспорт точек в GPX.
- Полевой режим без загрузки источников и подложки, встроенные подтверждения, защита черновиков и конфликтов между вкладками.
- Локальное хранение, экспорт/импорт JSON с валидацией.
- Service worker для автономной оболочки. Без сети видны точки и координатная сетка; онлайн-подложка не сохраняется для автономного использования.

## Алгоритм

Кандидаты: открытые проблемы, непроверенные объекты, записи старше 14 дней. Устранённые проблемы исключаются из плана и счётчика проверок. Оценка = приоритет (45/25/10) + открытая проблема (40) + источник воды (12) + давность (до 30). Сравниваются три жадных обхода: по отношению оценки ко времени, по близости и по абсолютной оценке. Выбирается наибольшая суммарная оценка, при равенстве — меньшее время. В расчёт входит 8 минут осмотра и запас на возврат. Расстояния — Haversine по прямой. Глобальный оптимум не гарантируется. Баллы условные, не научная оценка пожарной опасности. GPX содержит отдельные точки, а не вымышленный дорожный маршрут.

## Ограничения прототипа

Подключены погода Open-Meteo, водные объекты OpenStreetMap и европейская выгрузка термоаномалий NASA FIRMS VIIRS S-NPP за 24 часа. Сервер фильтрует данные и показывает происхождение и время. Нет дорожной маршрутизации, проверки фактической доступности воды, общей базы журнала или синхронизации сотрудников. Результат — план предварительного обследования, не руководство для тушения и не безопасный маршрут эвакуации. Состояние на местности проверяет человек.

Данные хранятся в localStorage данного браузера. Фото ограничены по размеру; при заполнении памяти приложение сообщает об ошибке и не принимает изменение. Экспортируйте резервные копии. Импорт заменяет журнал после подтверждения. На размещённом сайте localStorage отделён от localhost. При смене адреса переносите данные экспортом/импортом.

## Проверка

`npm test` — 30 тестов алгоритма, API, автономного кэша и рабочих сценариев DOM. Проверяются отмена/подтверждение импорта, черновики, фото после закрытия редактора, конфликт двух вкладок, нехватка памяти и восстановление повреждённого журнала. Карта и сеть в DOM-тестах заменены контролируемыми заглушками; визуальная проверка выполняется отдельно. Локальный адрес `/__qa/mobile` показывает приложение в iframe шириной 390 пикселей. Отчёт — [QA.md](QA.md).

## Для конкурса

Перед подачей необходимы реальные пилотные проверки с лесничеством, сравнение алгоритма с базовым подходом на одинаковых данных, публичный GitHub и видео до 3 минут. Этот прототип сам по себе не подтверждает новизну или эффективность. При использовании ИИ укажите это по правилам конкурса.
