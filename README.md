# Лесной дозор · 0.2

Полевой журнал подготовки к лесным пожарам с реальными открытыми данными. Учебные точки при первом запуске не создаются. Описание подключений и их ограничений: [LIVE-DATA.md](LIVE-DATA.md).

## Запуск

Установите Node.js 22 или новее, затем в этой папке выполните `npm start` и откройте http://localhost:4173. Установка пакетов и API-ключи не нужны. Не запускайте через file://: автономная загрузка требует HTTP localhost или HTTPS. Исходники интерфейса в `web/`, API в `worker/`. `npm run build` создаёт Worker со встроенными ресурсами в `dist/server/index.js`.

## Возможности

- Реальная онлайн-карта OpenStreetMap через локально поставляемый Leaflet 1.9.4.
- Добавление точек кликом по карте или по координатам; тип, приоритет, состояние, дата проверки, ответственный и срок устранения.
- Фото с локальным уменьшением до 900 пикселей, просмотр и удаление.
- Поиск, фильтры, задачи и история изменений.
- План проверок с ограничением времени, временем осмотра и возвратом на базу; сравнение с обходом ближайших точек.
- Локальное хранение, экспорт/импорт JSON с валидацией.
- Service worker для автономной оболочки. Без сети видны точки и координатная сетка; онлайн-подложка не сохраняется для автономного использования.

## Алгоритм

Кандидаты: открытые проблемы, непроверенные объекты, записи старше 14 дней. Устранённые проблемы исключаются. Оценка = приоритет (45/25/10) + открытая проблема (40) + источник воды (12) + давность (до 30). На каждом шаге выбирается допустимая точка с максимальным отношением оценки к затратам времени. В расчёт входит 8 минут осмотра и запас на возврат. Расстояния — Haversine по прямой. Это жадная эвристика, глобальный оптимум не гарантируется. Баллы условные, не научная оценка пожарной опасности. Сравнение с ближайшими точками может оказаться как лучше, так и хуже.

## Ограничения прототипа

Подключены погода Open-Meteo, водные объекты OpenStreetMap и европейская выгрузка термоаномалий NASA FIRMS VIIRS S-NPP за 24 часа. Сервер фильтрует данные и показывает происхождение и время. Нет дорожной маршрутизации, проверки фактической доступности воды, общей базы журнала или синхронизации сотрудников. Результат — план предварительного обследования, не руководство для тушения и не безопасный маршрут эвакуации. Состояние на местности проверяет человек.

Данные хранятся в localStorage данного браузера. Фото ограничены по размеру; при заполнении памяти приложение сообщает об ошибке и не принимает изменение. Экспортируйте резервные копии. Импорт заменяет журнал после подтверждения. На размещённом сайте localStorage отделён от localhost. При смене адреса переносите данные экспортом/импортом.

## Проверка

`npm test` — 10 тестов бюджета плана, кандидатов, приоритетов, импорта и API: валидация запросов, разбор CSV NASA с UTC, геометрия OSM и отсутствие произвольного прокси. Проверка синтаксиса: `node --check web/app.js` и `node --check web/live.js`. Проверены реальные запросы к погоде, OSM, NASA и поиску населённых пунктов.

## Для конкурса

Перед подачей необходимы реальные пилотные проверки с лесничеством, сравнение алгоритма с базовым подходом на одинаковых данных, публичный GitHub и видео до 3 минут. Этот прототип сам по себе не подтверждает новизну или эффективность. При использовании ИИ укажите это по правилам конкурса.
