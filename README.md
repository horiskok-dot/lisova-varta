# Лісова варта

[![Перевірка коду](https://github.com/horiskok-dot/lisova-varta/actions/workflows/check.yml/badge.svg)](https://github.com/horiskok-dot/lisova-varta/actions/workflows/check.yml)

**Польова мапа для підготовки до екстремальної спеки та лісових пожеж.** Вона поєднує відкриті картографічні й погодні дані з журналом фактичних перевірок. Працює як сайт, Android-застосунок і програма для Windows.

> **Важливо:** позначка на мапі або теплова аномалія не підтверджує пожежу, наявність води чи безпечний під’їзд. Рішення на місці приймає людина після перевірки. Застосунок не призначений для керування гасінням або евакуацією.

## Спробувати

[Відкрити сайт «Лісова варта»](https://forest-watch-field.shrewd-earth-4564.chatgpt.site/#/map). Якщо сайт вимагає вхід до ChatGPT, запустіть його локально за інструкцією нижче: поточна публікація може бути доступна лише власнику.

**Готові застосунки:** [Android APK і Windows x64](https://github.com/horiskok-dot/lisova-varta/releases/tag/v0.7.0). Як їх установити: [APPS.md](APPS.md).

1. Знайдіть населений пункт України в пошуку над мапою. Для готового прикладу виберіть **Дніпро** й увімкніть **Ділянки Дніпра**.
2. Перегляньте контур лісу, парку або водойми. Контури походять з OpenStreetMap; це **не** записи про перевірку.
3. Відкрийте **Джерела**, щоб побачити погоду й спеку, водні об’єкти OSM або теплові аномалії NASA FIRMS з часом отримання даних.
4. Додайте власний об’єкт лише після вибору конкретного місця. Запишіть стан, фото, відповідального і дату перевірки; за потреби складіть план огляду та експортуйте журнал.

При першому запуску журнал порожній. Довільні «безпечні точки» на мапі не створюються. Пошук охоплює 33 743 населені пункти України; окремий шар Дніпра містить 536 контурів OSM. Це орієнтири для дослідження, а не повний реєстр усіх місць.

## Запуск із коду

Потрібен **Node.js 24.15 або новіший**. У корені репозиторію виконайте:

```bash
npm ci
npm start
```

Відкрийте [http://localhost:4173](http://localhost:4173). API-ключі й обліковий запис для локального запуску не потрібні. Не відкривайте `web/index.html` через `file://`: автономна робота й API потребують HTTP або HTTPS.

```bash
npm test                 # автоматичні перевірки
npm run build            # зібрати сайт і Worker у dist/
npm run build:mobile     # підготувати Android-проєкт
npm run build:desktop    # зібрати програму Windows
```

Для APK після `npm run build:mobile` потрібні JDK 21 й Android SDK Platform 36/Build Tools; у папці `android` виконайте `gradlew.bat assembleDebug`. Докладніше про обидві збірки та встановлення: [APPS.md](APPS.md).

## Що працює

- Супутникова й вулична мапи України, пошук населених пунктів, контури Дніпра, пошук найближчих водних об’єктів OSM.
- Погода Open-Meteo й теплові аномалії NASA FIRMS VIIRS S-NPP за останні 24 години; інтерфейс показує джерело, час даних і помилки завантаження.
- Локальний журнал із координатами, фото, пріоритетом, статусом, відповідальним, завданнями та історією змін.
- План огляду з бюджетом часу, часом на огляд і поверненням до початкової точки; експорт JSON і GPX.
- Польовий режим і автономна оболонка. Без мережі доступні власний журнал, пошук населених пунктів і вбудовані контури; онлайн-підкладка та нові дані з джерел потребують інтернету.

Дані журналу зберігаються **на цьому пристрої**, окремо для браузера, Android і Windows. Для перенесення між ними використовуйте експорт та імпорт JSON. Спільного облікового запису або синхронізації між пристроями зараз немає.

## Як влаштовано

- `web/` — український інтерфейс і локальні картографічні дані;
- `worker/` — серверні обробники відкритих джерел із перевіркою координат і кешуванням;
- `mobile/`, `android/` — оболонка Capacitor для Android;
- `desktop/` — оболонка Electron для Windows;
- `tests/` — перевірки алгоритму, API, автономної роботи й основних сценаріїв.

Алгоритм відбирає відкриті проблеми, неперевірені та застарілі записи, порівнює три евристичні порядки огляду й обирає той, що дає більше умовних балів у межах часу. Відстань обчислюється **по прямій**, тому результат не є дорожнім маршрутом, прогнозом ризику або доведеним оптимумом. Деталі й поточні обмеження описані в [LIVE-DATA.md](LIVE-DATA.md) та [QA.md](QA.md).
