# Приложения «Лесной дозор»

Один исходный код используется сайтом, Android APK и программой Windows. В Android и Windows интерфейс уже вложен в пакет, поэтому журнал, задачи, план обхода и координатная сетка и поиск по 33 743 населённым пунктам Украины открываются без интернета. Спутниковая подложка Esri, уличная карта OSM, погода, новые объекты OSM и спутниковые отметки требуют сети. Исходники сайта находятся в `web/` и `worker/`.

На телефоне разделы и добавление записи доступны в нижней панели. «Карта / Мои объекты» переключает рабочую область; меню в правом верхнем углу открывает полевой режим, экспорт, импорт, установку и помощь. На ПК карта и список показаны рядом. Кнопка с четырьмя уголками разворачивает карту; Escape сворачивает её.

## Android

Готовый файл после сборки: `releases/android/Lesnoy-Dozor-Android.apk`. Перенесите APK на телефон, откройте его и разрешите установку из этого источника, если Android спросит. Это отладочная сборка для прямой установки; для Google Play нужна отдельная релизная подпись. Требуется Android 7 или новее. Журнал хранится в данных приложения. Перед удалением или переустановкой сделайте экспорт.

В Android данные OSM и NASA загружаются непосредственно с открытых источников через встроенный HTTP-клиент. Для экспорта JSON или GPX откроется системное меню сохранения/отправки. Геолокация запрашивается только после нажатия «Моё место». Без телефона или эмулятора сборка проверяется компиляцией и содержимым APK; работу камеры, файлового меню и разрешений следует дополнительно проверить на устройстве.

Для пересборки: `npm ci`, `npm run build:mobile`, затем в папке `android` выполните `gradlew.bat assembleDebug`. Иконки и экран запуска генерируются автоматически из SVG. Нужны JDK 21 и Android SDK Platform 36/Build Tools. После сборки скопируйте `android/app/build/outputs/apk/debug/app-debug.apk` в `releases/android/`. На машине разработки SDK и JDK лежат в соседней папке `toolchain/`; это инструменты сборки, не часть исходного кода.

## Windows

Распакуйте `releases/Lesnoy-Dozor-Windows-x64.zip` целиком и запустите `Lesnoy Dozor.exe`. В архиве лежат необходимые файлы Electron; один `.exe` без соседних файлов не запустится. Windows может предупредить о неподписанной программе. Приложение сохраняет журнал отдельно от браузерного сайта.

Для пересборки: `npm ci`, затем `npm run build:desktop`. Проверка готового пакета: запустите `Lesnoy Dozor.exe --smoke-test`; успешный выход проверяет загрузку встроенного интерфейса. Файл `desktop/main.cjs` открывает локальный защищённый протокол `forest://app`, а `worker/` обрабатывает запросы к открытым данным внутри приложения.

## Установка сайта как приложения

Откройте [опубликованный сайт](https://forest-watch-field.shrewd-earth-4564.chatgpt.site/) в Chrome на Android или Chrome/Edge на ПК и нажмите «Установить приложение». На iPhone откройте сайт в Safari, нажмите «Поделиться» → «На экран Домой». На сайте может потребоваться вход в ChatGPT, поскольку публикация доступна владельцу. Журнал на сайте, в Android APK и в Windows программе хранится отдельно. Для переноса нажмите «Экспорт» на старом устройстве и «Импорт» на новом.

Автономная работа сайта начинается после успешного сохранения оболочки браузером. В установленных Android и Windows версиях оболочка уже входит в пакет. Карта-подложка и новые данные из сети офлайн недоступны во всех версиях.
