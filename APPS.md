# Застосунки «Лісова варта»

Сайт, Android APK і програма для Windows використовують той самий інтерфейс та логіку. Готові файли версії 0.8.0 можна завантажити в [релізі GitHub](https://github.com/horiskok-dot/lisova-varta/releases/tag/v0.8.0). Вихідний код сайту зберігається в `web/` і `worker/`.

Журнал на сайті, Android і Windows зберігається окремо. Для перенесення записів виконайте **Експорт JSON** на старому пристрої та **Імпорт** на новому. Перед видаленням застосунку збережіть резервну копію журналу.

## Android

Завантажте `Lisova-Varta-Android.apk` з релізу, відкрийте його на телефоні й дозвольте встановлення з цього джерела, якщо Android запитає. Це налагоджувальна збірка для прямого встановлення, а не підписаний реліз Google Play. Потрібен Android 7 або новіший.

Інтерфейс і локальні дані вбудовані в APK. Пошук 33 743 населених пунктів, журнал, завдання, план огляду та 536 контурів Дніпра доступні без мережі; супутникові знімки, погода, нові дані OSM і NASA потребують інтернету. Геолокація запитується після натискання **Моє місце**. Експорт використовує системне меню збереження/надсилання.

Для власної збірки: `npm ci`, `npm run build:mobile`, потім `gradlew.bat assembleDebug` у папці `android`. Потрібні JDK 21 та Android SDK Platform 36/Build Tools. APK з’явиться в `android/app/build/outputs/apk/debug/`.

## Windows

Завантажте `Lisova-Varta-Windows-x64.zip`, розпакуйте **весь архів** і запустіть `Lesnoy Dozor.exe`. Окремий EXE без сусідніх файлів Electron не працює. Windows може показати попередження, бо збірка не має комерційного підпису.

Для власної збірки: `npm ci`, `npm run build:desktop`. Вбудований тест завантаження: `Lesnoy Dozor.exe --smoke-test`. Програма відкриває локальний протокол `forest://app`; серверні обробники відкритих даних входять до пакета.

## Сайт як застосунок

Відкрийте [сайт](https://forest-watch-field.shrewd-earth-4564.chatgpt.site/#/map) у Chrome на Android або Chrome/Edge на ПК й виберіть **Установити застосунок**. Наразі сайт може вимагати вхід до ChatGPT, тому для незалежного показу використовуйте APK, Windows-архів або локальний запуск із GitHub. Після першого успішного завантаження браузер зберігає автономну оболонку. Онлайн-підкладка й нові дані джерел офлайн недоступні.

Перевірка на фізичному Android-пристрої, зокрема системних дозволів, залишається окремим етапом; APK успішно скомпільовано. Windows-пакет пройшов тест запуску.
